* **3D Scroll Animations:** Interactive objects shift rotation, depth position, and scale dynamically based on the user's scroll velocity.
* **Futuristic HUD Overlay:** Designed a clean, professional Head-Up Display text architecture over the 3D scene canvas without breaking layout balance.
